# NEON BASTION

Tower Defense futurista y PWA instalable. Tres mapas, 20 oleadas, cuatro tipos de torres con cuatro niveles, enemigos rápidos y blindados, jefes, economía, mejoras, venta, pausa, velocidades y récord local.

## Publicar

GitHub → Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.

URL prevista: https://ardu01.github.io/Tower-defense/

## Controles

Selecciona un tipo de torre y toca el tablero para construir. Toca una torre existente para mejorarla o venderla. Inicia oleadas manualmente.

Sin dependencias ni servicios externos. Los datos de récord se almacenan localmente.
